The frontend provides a dashboard-style interface for monitoring the autonomous AI agent, its topic discovery process, editorial decisions, and generated publications.

- Redesigned the frontend with a modern dark-themed AI/technology dashboard UI.
- Added an **Agent Identity** section displaying:
  - Persona name
  - AI domain
  - Agent status
  - Autonomous/Demo mode
- Added an **Overview Dashboard** with key metrics:
  - Sources monitored
  - Topics discovered
  - Topics rejected
  - Publications generated
- Added a **Live Scanning** section to represent monitoring of AI/security information sources.
- Added an **Agent Activity Timeline** showing the autonomous pipeline:
  - Scanning sources
  - Discovering topics
  - Evaluating relevance
  - Rejecting low-signal topics
  - Selecting topics
  - Publishing content
- Added an **Editorial Decision** panel showing the topic evaluation process and rejection/selection statistics.
- Added a **Live Intelligence / Feed** section for displaying generated AI-related publications.
- Added individual **Post Cards** containing:
  - Publication timestamp
  - Generated post
  - Publishing rationale
  - Information sources
- Added reusable UI components for:
  - Sidebar
  - Header
  - Status badges
  - Metrics
  - Activity timeline
  - Editorial decisions
  - Feed posts
- Added utility functions for formatting timestamps and API-related data.
- Added a frontend API service layer in preparation for backend integration.
